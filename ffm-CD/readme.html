The Future From Memory

System Requirements

  • 85Mb free hard disk space
  • Mac OS 8.5 with Carbonlib > 1.3.1
  • Fast processor, graphics card and plenty of RAM

Installation Instructions

All platforms

  • Copy all the files on this CD to your hard drive.
    DO NOT attempt to run Future From Memory from the CD!

Macintosh users

  • Double click on the file mac_projector.hqx
  • This should create a file called projector in the same directory
  • Double click on the projector file to run Future From Memory.

Windows users

  • Double click the file win_projector.exe to run Future From Memory.

NOTE: The projector files can be played on a computer without the need for installation of the Flash Player. Using these is the recommended way of playing FFM. Alternatively, you could install the Flash Player using the installers in the folder Flash Player, then open the first segment (segment1.swf) by double-clicking on it. There are players in the Flash Player folder which will install on Linux/Mozilla, Macintosh (Classic), Mac OSX and Windows 95/98/Me/NT/2000/XP.

CD Contents

  • readme.html
    This file.

  • mac_projector.hqx
    Macintosh projector file. This is encoded as an hqx file, and should be decoded automatically when double-clicked on a macintosh. Note that the decoded file is usually placed in the same folder as the encoded file, so your mac will ask you to choose a different location to store the decoded file if you double click the file on the CD. If you copied all files to disk first, this would not be a problem.

  • win_projector.exe
    Windows projector file. This is an executable file for Windows systems, and should run FFM when double-clicked.

  • segment1.swf, segment2.swf, segment3.swf, segment4.swf, segment5.swf
    Segments which make up FFM. These segments must be present in the same folder as the projector file for it to work.

  • src folder
    This folder contains all the source files for FFM (.fla files).

  • segment projector files folder
    This contains individual projectors for each of the segments (for proofing purposes).

  • Flash Player folder
    This contains installers for Flash Player 6 for different platforms.
